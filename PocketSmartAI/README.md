# PocketSmart AI

A complete FastAPI + Jinja2 + SQLite application based on the supplied PocketSmart AI project specification.

It includes:
- User registration, login, logout and JWT authentication
- Home Interior Budget Planner
- Party Budget Planner
- Jewelry Budget Planner with optional outfit image upload
- Gemini integration through the current `google-genai` SDK
- Safe demo fallback recommendations when no Gemini API key is configured
- Recommendation history
- Responsive HTML/CSS/JavaScript frontend
- VS Code configuration and launch/debug tasks

> The supplied project document mentions both Flask and FastAPI. This implementation follows the later FastAPI architecture and endpoints described in the document (`/generate-home`, `/generate-party`, `/generate-jewelry`, authentication/session routes, history, and startup).

## Requirements

- Python 3.11 or newer
- VS Code
- Internet access only when using Gemini
- A Gemini API key for live AI recommendations (optional for local demo mode)

## Installation

### Windows PowerShell

```powershell
cd PocketSmartAI
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

### macOS/Linux

```bash
cd PocketSmartAI
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
```

Edit `.env`:

```env
GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-2.5-flash
```

If `GEMINI_API_KEY` is blank, the application automatically uses deterministic demo recommendations, so the application still runs.

## Run

```bash
uvicorn app.main:app --reload
```

Open:

- http://127.0.0.1:8000
- http://127.0.0.1:8000/docs

The API documentation is generated by FastAPI.

## VS Code

1. Open the `PocketSmartAI` folder.
2. Select `.venv` as the Python interpreter.
3. Run **Terminal > Run Task > Install dependencies** once if needed.
4. Press `F5` and choose **FastAPI: Run development server**, or use the integrated terminal:
   `uvicorn app.main:app --reload`

## Notes about external platforms

The project specification names Amazon, Flipkart, IKEA, Swiggy, Zomato and OYO. This starter implementation does **not** scrape those sites and does not pretend to have live inventory. Recommendations contain platform search links. Real affiliate/product APIs can be connected later in `app/services/recommendation_service.py`.

## Security

- Passwords are hashed with Argon2 through `pwdlib`.
- JWTs are signed with a configurable secret.
- The app validates planner inputs with Pydantic.
- Upload size/type checks are applied to jewelry images.
- `.env` is ignored by Git.

For production, use HTTPS, a strong secret, a managed database, rate limiting, secure cookies/token storage, and real provider APIs.
